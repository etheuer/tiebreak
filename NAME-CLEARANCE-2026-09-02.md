# Tiebreak name clearance — 2 September 2026

This is a knockout research memo, not legal advice and not a clearance opinion. Nothing was bought, filed, or pointed at DNS. A trademark lawyer still has to run a paid search before anyone files a mark or spends real money on this name.

Checked on 2 September 2026. Official USPTO TSDR JSON returned 401 from this environment; TMview/EUIPO search APIs reset the connection. US serial statuses below are from Justia/Trademarkia pages that cite TSDR. Domain facts are from RDAP/WHOIS. Company facts are from Companies House.

---

## Bottom line

The word is **not clear as a brand**.

There is **no live US federal registration for the exact word TIEBREAK on software or comparison websites**. That is not the same as “you can have it.” The name is a generic tennis term, already used by several live apps, a licensed ATP/WTA video game, a UK company sitting on `tiebreak.app`, and a Vancouver SaaS company filing **TIEBREAKER AI** in class 042.

The practical problem is crowding and the domain, not a single identical USPTO block.

**Do not point this product at `https://tiebreak.app`.** That domain is already a live UK tennis-court app. The site’s fallback URL in code is currently that address.

**Recommended next step:** treat Tiebreak as a working title, not the public brand, until you either (a) rename while traffic is near zero, or (b) keep the word, buy a domain you actually control, and have counsel run a full search before filing. Cost of waiting: every comparison page you publish under this name becomes a rename later.

---

## 1. What “clear” would have to mean

Clearance is not “is the dictionary word free.” It is whether you can use **Tiebreak** as a consumer brand for a US/UK comparison website without:

- walking into someone else’s registered mark in related classes (roughly 9, 35, 41, 42)
- colliding with a live product people already call Tiebreak
- owning a domain people will actually type
- being able to register the mark later if you want exclusivity

On those tests the name fails 2, 3, and 4. Test 1 is mixed: no identical live TIEBREAK software registration showed up in the US; several nearby live marks and a pending **TIEBREAKER AI** class-042 application did.

The word is also **descriptive/generic in tennis** (the scoring format). That makes later registration harder, and it is why so many unrelated products picked it.

## 7. What this means for *this* product

The live site today is on Vercel (`tiebreak-gilt.vercel.app` / `tiebreak-et-projects.vercel.app`). Custom domain was not pointed. That is lucky: you have not yet taught Google that the comparison site *is* `tiebreak.app`.

If you keep the name:

1. Leave DNS alone. Never attach `tiebreak.app`.
2. If you need a human URL, pick one of the unregistered names you can actually buy, after a registrar check.
3. Do not file a trademark yourself. Counsel should search USPTO, UK IPO, EUIPO/TMview, CIPO, and common-law use, then decide classes (likely 35 and 42, maybe 9).
4. Expect a crowded-field / descriptiveness fight if you file. “Tiebreak” as “the thing that decides which product wins” is clever copy and a weak mark.
5. Stay visually and verbally away from tennis, ATP, WTA, and court-booking.

If you rename:

- Do it now. There is almost no SEO or inbound-link cost yet.
- Pick a word whose `.com` or `.app` you can buy today, then search that word the same way.

I would **not** spend the next year building public reputation under Tiebreak unless you have already accepted that you will never own `tiebreak.com` / `.app` / `.io` and may never get a strong registered mark.
