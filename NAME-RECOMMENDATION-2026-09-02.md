## Primary name: **Clinchmark**

A coined compound of *clinch* (settle the contest) and *benchmark* (the spec you measure against). It is for this head-to-head product-comparison / verdict site. It is not Tiebreak, Tie-break, Tiebreaker, or Tiebreakers.

**Recommended domain (exact): `clinchmark.com`**

Checked 2 September 2026:

- Verisign RDAP `https://rdap.verisign.com/com/v1/domain/clinchmark.com` → **HTTP 404**
- `whois -h whois.verisign-grs.com clinchmark.com` → **No match for domain "CLINCHMARK.COM"**

RDAP 404 is not a purchase lock. The name can register between this check and a buy.

## IP-risk note (knockout, not clearance)

**Exact CLINCHMARK**

- Live consumer product / app / comparison site: **none found in this knockout**
- USPTO-adjacent (Justia / Trademarkia) exact word in classes 9, 35, 41, 42: **none found in this knockout**
- App Store / Google Play listing named Clinchmark: **none found**

**Nearby (say this to a lawyer; residual, not a kill on this knockout)**

- **CLINCHECK (Align Technology) is live software, not only class 044.** Same CLINCH- prefix, different second half (CHECK vs MARK). Goods are dental/orthodontic imaging, not consumer product comparison. Still the closest class 9/42 residual:
  - Class **009** — live/renewed [75695982 / 2392324](https://trademarks.justia.com/756/95/clincheck-75695982.html): “computer software, namely digital imaging software used to depict tooth movement and proposed treatment plan.” Status 800 Registered and Renewed (status date 15 Dec 2020).
  - Class **042** — [88016081](https://trademarks.justia.com/880/16/clincheck-88016081.html): non-downloadable online digital-imaging / dentistry SaaS. Justia last observed **819 SU — Registration Review Complete** (1 Feb 2022). Also **CLINCHECK WEB** [86101830 / 4773545](https://huski.ai/trademark-details-mark-clincheck-web-serial-number-86101830), class **042**, registered and renewed 14 Oct 2025.
  - Class **044** — live/renewed [78576566 / 3366656](https://trademarks.justia.com/785/76/clincheck-78576566.html): orthodontic and dental *services*. Extra to the software filings, not instead of them.
- **CLINIMARK** — cancelled §8 in 1993, class 042 clinical trials ([73626632](https://trademarks.justia.com/736/26/clinimark-73626632.html)). Dead.
- **CLINCHEK** — live lab-reagent mark, not a consumer comparison site ([79063732](https://trademarks.justia.com/790/63/clinchek-79063732.html)).
- **CLINCH** (no “mark”) is crowded in software: recruitment SaaS [90178872](https://furm.com/trademarks/clinch-90178872) classes 9/35/42; ad-tech at clinch.co; a pending sports-game CLINCH. The recommended word is the compound **Clinchmark**, not Clinch.

Keep **Clinchmark**: exact word still has no live product or class 9/35/41/42 hit in this knockout; `clinchmark.com` is unregistered. Do not treat CLINCHECK as “different class.” Align is a large software owner in 9 and 42. A paid search can still kill the pick.

Keep shipping the comparison site under the current working title for now — this memo does **not** rename anything.
